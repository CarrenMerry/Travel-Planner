// From com.wayfarer.ds.CustomLinkedList<E>
public void swap(int index1, int index2) {
    if (index1 == index2) return;
    Node<E> node1 = getNode(index1);
    Node<E> node2 = getNode(index2);
    // Swapping internal references or node payload atomically
    E temp = node1.data;
    node1.data = node2.data;
    node2.data = temp;
}
// Guarantees O(1) pointer adjustment once nodes are resolved, without array shifting!

Greedy Multi-Factor Recommendation Heuristic

Class: com.wayfarer.algorithm.GreedyRecommendationService — Iterative local optimization algorithm selecting highest-scoring candidates under budget constraints.

Time Complexity: O(K × N)

Academic Scoring Function

Score(d) = 0.40 × (Rating / 5.0) + 0.35 × (CategoryMatch ? 1 : 0) + 0.25 × (1 - Cost / RemainingBudget) + (Connected ? 0.10 : 0)

At each iteration, the algorithm computes this score for every unvisited destination that fits within the remaining budget. The maximum is greedily chosen, budget is deducted, and the process repeats for K desired stops.
