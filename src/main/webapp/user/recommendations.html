DSA Academic Requirement 4: Greedy Destination Recommendation

The recommendation engine uses a genuine Java Greedy Algorithm (O(K • N)). At each step, it evaluates all eligible candidates against: Score = (Rating/5.0 • 0.40) + (CategoryMatch • 0.35) + (BudgetViability • 0.25) + (DirectTransitBonus • 0.10). The candidate with the highest local score is locked in and its cost is deducted from the remaining budget. Greedy heuristics make locally optimal choices; they do not explore exponential subsets for global optimality.
