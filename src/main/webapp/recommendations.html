Academic Algorithm Details • Greedy Multi-Factor Scoring

Algorithm: com.wayfarer.algorithm.GreedyRecommendationService

At each iteration, the algorithm computes a dynamic heuristic score for every candidate unvisited destination using the formula:

Score = (Rating / 5.0) × 0.40 + (Category Affinity) × 0.35 + (Budget Viability) × 0.25 + (Direct Connection Bonus) × 0.10

The highest scoring candidate within the remaining budget is selected as the local optimum. Because the algorithm chooses the best immediate candidate without recursive backtracking, it executes in efficient $O(K \cdot N)$ time.
